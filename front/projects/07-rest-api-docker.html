section 01 — flow

Du commit au prod en quelques minutes.

Le repo Git déclenche une CI à chaque push : lint, tests unitaires, construction de l'image Docker, push vers la registry. Le déploiement en production se fait en rolling update, avec zéro downtime grâce aux health checks. Les métriques applicatives remontent vers Grafana ; les logs sont structurés en JSON.
