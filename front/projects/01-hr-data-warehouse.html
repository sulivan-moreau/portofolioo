section 01 — architecture

Trois sources, un warehouse, deux consommateurs.

Le pipeline absorbe des données SAP HR, des extracts CSV historiques et une API RH interne. Talend orchestre la chaîne ETL : nettoyage, dédoublonnage, application SCD2 pour historiser les changements d'état (poste, contrat, équipe). Les modèles sont ensuite chargés dans Oracle, puis exposés à Power BI via une couche sémantique DAX.
